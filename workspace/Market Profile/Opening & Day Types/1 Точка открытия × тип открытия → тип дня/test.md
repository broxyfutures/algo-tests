## Идея

У Далтона в самом месте открытия и в том, как рынок ведёт себя в первый час, уже заложен потенциальный тип дня. Вопрос: **с какой вероятностью формируется каждый тип дня при данной точке открытия и данном типе открытия.** Матрица: 5 зон дают 17 ячеек, 3 группы — 9.

## Переменные

| Переменная | Что это |
|---|---|
| Точка открытия | цена 09:30:00 против опоры: выше диапазона / выше VA в диапазоне / внутри VA / ниже VA в диапазоне / ниже диапазона |
| Опора | VA, high и low вчерашнего профиля; с тумблером — открытого композита от 2 дней |
| Тренд точки открытия | выше VA → лонг, ниже VA → шорт, внутри VA → нет |
| Своя граница VA | VAH при лонге, VAL при шорте |
| Блоки | A = 09:30–10:00, B = 10:00–10:30, IB = A + B, цена в 10:30 = закрытие B, следующий час = 10:30–11:30 |
| Касание | цена дошла до уровня с точностью 1 тик |
| Пробой IB по тренду | в 10:30–11:30 цена хотя бы на тик выше хая IB при лонге, ниже лоу IB при шорте |

## Метод и исключения

**Открытие внутри VA → Open-Auction внутри VA.**

**Открытие вне VA**, по порядку:

1. **Своя граница VA коснулась за 09:30–10:30.** Цена в 10:30 внутри VA или прошла её насквозь → **Open-Rejection-Reverse**. Снова за VA со стороны открытия → кандидат в Open-Test-Drive (шаг 3).
2. **VA не коснулась.**
   - Открытие внутри вчерашнего диапазона: в B цена вернулась к экстремуму A против тренда → кандидат (шаг 3), иначе **Open-Drive**.
   - Открытие за диапазоном: в B цена коснулась вчерашнего high (лонг) / low (шорт) → кандидат (шаг 3). Иначе, если в B экстремум A не пробит → **Open-Drive**, если пробит → **Open-Auction вне VA**.
3. **Кандидат:** пробой IB по тренду в 10:30–11:30 → **Open-Test-Drive**, нет → **Open-Auction вне VA**.

| | |
|---|---|
| Когда тип известен | в 10:30: Open-Drive, Open-Rejection-Reverse, Open-Auction внутри VA; к 11:30: Open-Test-Drive и Open-Auction вне VA |
| Направление типа открытия | Open-Drive и Open-Test-Drive по тренду точки открытия, Open-Rejection-Reverse против |
| Выборка | все полные RTH-дни 2010-07 → 2026-09 |
| Исключены | укороченные дни, дни без опоры (первый день истории, дни после дыр в данных) |
| Дни ролла | включены, вчерашние уровни сдвинуты на спред между контрактами |
| Порогов нет | статистика описательная |
