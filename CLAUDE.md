# Algo-Tests: правила работы

Два пайплайна и статический сайт с результатами. Инструмент — ES (e-mini S&P 500), данные Databento.

| Папка | Что это |
|---|---|
| `mp-es-pipeline/` | Market Profile: TPO-профили день / неделя / месяц, типы дня и открытия, композиты, тесты |
| `cot-es-pipeline/` | COT Report и price action. Серия закрыта: преимущества не нашли, тесты оставлены как архив |
| `workspace/` | сайт: папка = страница, `build.py` собирает `index.html` рядом с исходниками |

## Что можно пересчитать без сырых данных

Сырые минутки (`cot-es-pipeline/data/es`, 82 МБ) в git **не лежат** — они в `.gitignore` и качаются
из Databento скриптом. В репозитории есть `mp-es-pipeline/data/derived/periods_30m.parquet`
(30-минутные блоки всех сессий) и все производные CSV, поэтому:

| Шаг | Нужны минутки | Что делает |
|---|---|---|
| `01_build_periods.py`, `02_build_profiles.py` | **да** | периоды и дневные профили: VA, POC, IB, хвосты, ночь, объём |
| `04` … `07`, `11`, `12` | нет | недельные и месячные профили, типы дня, композиты, типы открытия, тесты, данные графика |
| `workspace/build.py` | нет | сборка сайта |

В облачной сессии (без минуток) можно менять классификаторы, тесты, сайт и рендереры. Менять размер
строки, правила value area, ночную сессию и объёмные метрики — только на машине с сырыми данными.

Зависимости: `pip install -r mp-es-pipeline/requirements.txt` (pandas, numpy, pyarrow).

## Правила, которые нельзя менять молча

- **Параметры профиля заморожены** трейдером: VA 68 %, excess и single prints от 2 блоков TPO,
  последний блок профиля не может дать excess, IB = 2 блока по 30 минут, poor high/low = 2 блока
  в ширину, RTH 09:30–16:00, ETH с 18:00. Всё в `config.py`, описано в `PROFILE_RULES.md`.
- **Любой тест считается в двух режимах блока сразу**: фиксированный (день 2 пт, неделя 4, месяц 8 —
  как в терминале трейдера) и адаптивный. Результаты показываются рядом.
- **Правила замораживаются до просмотра результатов.** Сначала согласовать формулировку с трейдером,
  потом считать. Любое изменение правила — запись в журнал страницы и в `PROFILE_RULES.md`,
  пересчёт затронутых тестов.
- **Порогов «прошло / не прошло» нет.** Статистика описательная, выводы делает трейдер.
- Типы дня и типы открытия — по Mind Over Markets (Далтон) с поправками трейдера, раздел 6 и 7
  в `PROFILE_RULES.md`.

## Сайт

Публикуется на GitHub Pages из ветки `main` (`.github/workflows/pages.yml`):
https://broxyfutures.github.io/algo-tests/. Netlify-зеркало с 26.09.2026 не собирается — кончились
кредиты бесплатного плана.

CI гоняет только `build.py`, пайплайн не запускает. Поэтому в коммит должны попадать и
`results.json` тестов, и `workspace/assets/data/mp_chart_data.js` (выгрузка шага 12).

Страницы пишутся по-русски, без em-тире, без маркетинговых слов. Локально сайт открывается и без
сервера: `workspace/index.html` по file://.

## Порядок пересчёта

```
01 → 02 → 04 → 05 → 06 → 07 → 11 → 12 → workspace/build.py
```

После правки `config.py` или правил классификации пересобирать с того шага, которого правка касается,
и обязательно 11 и 12, иначе таблицы и график разойдутся с данными.
