# Algo-Tests

Проверки торговых инструментов на исторических данных. Каждый тест отвечает на один заранее сформулированный вопрос, критерии прохода фиксируются до запуска, вердикт записывается независимо от того, положительный он или нет.

**Сайт с результатами:** https://algo-tests.netlify.app

## Что внутри

| Папка | Что это |
|---|---|
| `workspace/` | Рабочее пространство тестов. Принцип «папка = сайт»: каждая папка превращается в `index.html` рядом со своими исходниками, имена папок становятся хлебными крошками. Текст тестов в `test.md`, числа в `results.json` |
| `cot-es-pipeline/` | Пайплайн данных для первой серии тестов: COT-отчёт CFTC против ES (S&P 500) |
| `mp-es-pipeline/` | Пайплайн второй серии: Market Profile по ES, восстановленный из тех же минуток (TPO, value area, IB, ночь). Описание в `mp-es-pipeline/README.md` |

## Первая серия: COT → ES

Вопрос: меняет ли позиционирование крупных участников в отчёте CFTC распределение недельных и понедельничных исходов по фьючерсу ES.

- Отчёт: CFTC, Traders in Financial Futures, Futures Only, строка S&P 500 Consolidated
- Группы: Leveraged Funds (основная гипотеза), Asset Managers (второй прогон)
- Метрика: COT Index Уильямса по чистой позиции, окно 52 недели, состояния Low ≤ 20 / Mid / High ≥ 80, второй порог 10/90
- Цена: минутки ES из Databento, RTH 09:30–16:00 Нью-Йорк, недельные и понедельничные ходы в процентах
- Критерий прохода: n ≥ 30 недель в состоянии, разница с контрольной группой Mid ≥ 10 процентных пунктов, тот же знак на обоих порогах

Итог: уровень позиционирования как самостоятельная переменная на недельном горизонте по ES закрыт. Подробные таблицы, вердикты и журнал решений на сайте.

## Вторая серия: Market Profile → ES

Market Profile восстановлен из минуток ES за 2010–2026: 4088 дневных профилей (RTH, блок 30 мин), 850 недельных (блок 4 ч) и 196 месячных (блок 1 день). Каждый профиль считается в двух режимах размера блока: фиксированный (2 / 4 / 8 пунктов, как в терминале) и адаптивный к волатильности. Дневные профили дополнительно склеиваются в композиты по перекрытию VA (тумблер в тестах). Правила типов дня и открытия фиксируются до первого теста. Тесты в `workspace/Market Profile/`.

```bash
cd mp-es-pipeline
python3 scripts/01_build_periods.py     # 30-минутные периоды (буквы профиля)
python3 scripts/02_build_profiles.py    # дневные профили, два режима блока
python3 scripts/04_build_weekly_monthly.py  # недельные и месячные профили
python3 scripts/05_build_day_composites.py  # дневные композиты (тумблер)
python3 scripts/03_print_day.py 2025-01-17   # профиль дня для сверки с терминалом
```

## Как запустить у себя

```bash
pip3 install -r cot-es-pipeline/requirements.txt
```

Сырые данные в репозиторий не входят (около 130 МБ), они качаются скриптами. Производные файлы (`cot-es-pipeline/data/derived/`) закоммичены, поэтому шаги 6 и 8 можно запустить сразу, без ключа Databento.

```bash
cd cot-es-pipeline
python3 scripts/01_download_cot.py      # COT из CFTC, бесплатно
python3 scripts/02_cot_index.py         # индекс и состояния
cp .env.example .env                    # сюда ключ Databento для шага 3
python3 scripts/03_download_es.py --confirm
python3 scripts/04_build_daily.py
python3 scripts/07_build_path.py
python3 scripts/06_export_results.py
python3 scripts/08_export_yesno.py
python3 ../workspace/build.py           # собрать страницы
```

Открыть `workspace/index.html`. Подробности по данным, ловушкам формата CFTC и выравниванию по времени в `cot-es-pipeline/README.md`.

## Добавить свой тест

Создать папку в нужном разделе `workspace/`, положить в неё `test.md` по образцу любого готового теста, запустить `python3 workspace/build.py`. Схема `test.md` и список рендереров в разделе 7 файла `cot-es-pipeline/README.md`.
