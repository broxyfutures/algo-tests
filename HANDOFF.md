### Тест 3 «Место и тип открытия → тест границ IB» (Strong Points 1)
Зачем: где статистически ставить стоп и тейк, чтобы стоп не выбило, а тейк сработал.
Мои правила (03.10):
1. Тест границы = цена дошла до хая IB или выше / до лоу IB или ниже. **Ровно уровень**, без допуска.
2. IB = 09:30–10:30 (блоки A + B). Тест ищется в **10:30–16:00**, только RTH (держу позиции до конца RTH).
3. Калькулятор [точка открытия] + [тип открытия]. **Тип дня не используется** (известен только к концу дня).
   Open-Test-Drive ничем не помечается. (С новой редакции типов открытия от 03.10 пробой IB в 10:30–11:30
   в определение Open-Test-Drive больше не входит, см. PROFILE_RULES, раздел 7.)
4. Тумблер «Исход», три вида: «Нет / одна / обе»; «Хай / лоу / обе / нет»; «По тренду открытия»
   (открытие выше VA: граница по тренду = хай IB, «только по тренду» = лоу IB не тронут = Strong Low;
   ниже VA наоборот, Strong High; открытия внутри VA в этом виде не участвуют).
Числа, все 4050 дней: только хай 37.8 %, только лоу 30.6 %, обе 29.7 %, нет 2.0 %.
По тренду (2490 дней вне VA): только по тренду 35.2 %, только против 34.6 %, обе 28.1 %, нет 2.0 %.
Пример: выше VA в диапазоне + Open-Drive (95 дней): только по тренду 48.4 % (+13.2 п.п.).

Про опору «композит»: IB всегда свой, дневной, исход дня от опоры не зависит. Опора меняет только точку и тип
открытия (зона меняется у 7.4 % дней, тип у 6.2 %), поэтому меняется состав ячеек калькулятора и вида «по
тренду», а кольцо «хай / лоу / обе / нет» по всем дням не меняется.

### Плитка «Какая граница протестирована первой?» (Strong Points 1б), на странице теста 3
Мои ответы (03.10):
1. Только дни с тестом обеих границ. Виды: хай / лоу; по тренду / против; в виде «нет / одна / обе» как хай / лоу.
2. Обе границы в одном 30-минутном блоке: порядок **по минуткам**, но только для этих дней (не весь тест).
3. Тест как в Strong Points 1, «первая» = коснулась раньше.
4. Своего калькулятора нет, выбор берётся из основного.
5. Горизонтальная полоса: общая по выборке + полоса и плитки выбора с разницей в п.п.
6. Фильтр «Вторая граница»: Все / В этот же блок / через [N] блоков (поле ввода, ровно N блоков).
7. Название «Какая граница протестирована первой?», пометка «только дни, когда протестированы обе
   границы IB» в плитке и на странице «Правила».
Числа (1201 день с обеими): первым хай 47.9 %, первым лоу 47.5 %, в одном блоке 4.6 % (55 дней, 48 из них в
блоке C). Пример: выше VA в диапазоне + Open-Drive, 28 дней с обеими: первой граница по тренду 78.6 % (+31 п.п.).
